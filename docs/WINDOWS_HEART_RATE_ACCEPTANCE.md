## 实机复测

1. 从隔离测试入口启动。佩戴手环、开启心率广播并靠近电脑，在顶栏「心率」中扫描并选择手环。
2. 确认出现订阅提示及连续有效读数，关闭面板，观察顶栏继续更新。仅记录连续通知次数和持续时间。
3. 关闭广播，记录从最后一条通知到顶栏清除旧值的时间。恢复广播并点击「重新连接」，核对新通知，最后停止并退出。
