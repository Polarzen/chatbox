## 首包安装与现场结果

首包来自提交 `9dc7965537711030ecdb1a9672ce41c86142a6b8`，MSI 的 SHA-256 为 `510261a0421b97dfac46539aefdd0da481dce3699882a2d3edae882353d0ff92`。用户确认 UAC 后，从 0.1.13 原目录升级，退出码为 0。实际安装的 179 个文件与首包内容逐一匹配。67 个日常配置文件的哈希均与升级前正常退出时一致。

核对已注册的开始菜单快捷方式，目标为 `D:\chat box\Chatbox.exe`，应用标识（AUMID）为 `Polarzen.Chatbox`，通知激活类（ToastActivatorCLSID）为 `{4A8033D8-D9A3-499E-BDC1-EB485352F0DF}`。协议处理器命令行的参数双引号已核对无误。

**A 通过。** 用 Win+Shift+S 截图，从外部程序通过快捷键唤起并粘贴，收起再恢复后草稿和附件均保留。再次从开始菜单启动，第二个进程将唤起请求交给原窗口。已核对按键重复和快捷键冲突行为。现场观察保存在本地 `qa/evidence/observations.jsonl`。

**B 首次发送未通过。** 回复完成时 Windows 未显示通知。读取通知设置的 `Setting()` 调用返回 `0x80070490`。首包提交的 Windows 和 Android 回归 CI 均通过。[首包 CI](https://github.com/Polarzen/chatbox/actions/runs/45244227903)
