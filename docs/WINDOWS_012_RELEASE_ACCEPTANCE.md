# Chatbox 0.1.12 Windows 发布验收

## 0.1.11 基线

本轮从已发布的 v0.1.11 接续。PR #7 已合并到 `main`，提交为 `e1b0cb4`，修复了顶栏跨越 639/640 dp 布局切换点时的崩溃。下表的候选安装版结果单独核对。[0.1.11 Release](https://github.com/Polarzen/chatbox/releases/tag/v0.1.11) · [PR #7](https://github.com/Polarzen/chatbox/pull/7) · [合并后 CI](https://github.com/Polarzen/chatbox/actions/runs/45207040358)

## 0.1.12 安装版验收

| 项目 | 需要实测的行为 | 当前证据 |
| --- | --- | --- |
| A · 截图与文本粘贴 | Win+Shift+S 截取合成图，输入框 Ctrl+V 显示图片预览。中文、换行和替换选区均可用。搜索框和改名框各自处理粘贴。 | 待安装版实测 |
| B · 两张图的草稿恢复 | 连续粘贴两张不同截图，输入多行和末尾字符后立即正常退出。更换剪贴板，从开始菜单重开仍保留原文和图片顺序。移除一项再重开后只剩另一项。 | 待安装版冷启动实测 |
| C · 会话和配置隔离 | 同名会话和另一配置分别保留自己的草稿，改名不影响归属。在隔离数据中完成保存后异常退出，重开可恢复。 | 待安装版及隔离数据实测 |
| D · 缺失外部图片 | 移走一张已选图片后，显示缺失文件名，文字及另一张图保留。处理缺失项后可发送，外部原件保留。 | 待安装版实测 |
| E · 主动发送 | 粘贴、搜索、退出和恢复时上传与聊天计数均为 0。主动发送图文时上传 2 次、聊天提交 1 次。已发图片进入历史，延迟回复完成或失败后仍保留下一条草稿。 | 待安装版及隔离服务计数 |
| F · 窄窗口回归 | 同时开启置顶、深色主题及 75% 不透明度，窗口跨越 639/640 dp 并收放侧栏后，输入、附件预览、外观菜单和搜索均可操作。 | 待候选安装版实测。[0.1.10 窗口验收](WINDOWS_010_RELEASE_ACCEPTANCE.md) |
| G · 同一回复的两段语音 | 8 秒单声道显示 `0:08`，65 秒双声道显示 `1:05`。播放、停止、自然结束和离线重开时分别核对两段的标签。 | 待安装版播放及离线恢复实测 |
| H · WAV 边界与缓存 | 不足 1 秒及带元数据块的有效样本显示正确时长。损坏或缺失时显示提示，取回有效缓存后显示时长。没有音频输出设备时仍可读取缓存时长。 | 待样本回归及无输出设备验证 |
| I · 真实麦克风与 AstrBot | 从开始菜单启动，取消一次后再录制、停止、试听并保存草稿。重开后主动发送，核对一次上传、一次聊天和服务端可读取的录音段。待发和自发语音时长一致，离线重开可播放。 | 待真实麦克风、实际 AstrBot 及安装版核对 |
| J · 纯语音、混合发送与失败恢复 | 实际发送纯语音，再发送图片、语音和文字，核对附件与消息段。隔离测试无麦克风、上传被拒及提交结果不确定时的草稿恢复与人工重试。录音中切换会话，片段留在原会话，设备释放。 | 待真实设备、实际 AstrBot 及隔离故障测试 |

截图证据待采集。图文流程使用同一组合成数据展示粘贴后、退出重开及主动发送后的历史。语音流程分别展示待发录音、自发语音气泡及助手语音气泡中的总时长。
