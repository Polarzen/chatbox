## 后台慢回复的复测步骤

瑶已在 Redmi Turbo 3 上验证当前候选：前台回复完成后无提醒；后台慢回复完成后，亲自点通用通知可冷启动回到原轮。[真机结果](ANDROID_PARITY_ACCEPTANCE.md)

在「窗口外观」开启后台回复通知，并在系统设置授予 Chatbox 通知权限。在本机会话向测试服务发送一条带唯一标记、需要超过 7 秒才能完成的提问。发送后立即按 Home，保持后台超过 7 秒，直至回复完成。传输期间系统可能显示独立的无声进度通知「正在传输消息或附件」，传输结束后应消失。点击随后出现的通用回复完成通知，核对是否回到原会话、原轮的完整回复。记录 APK 摘要、按 Home 至完成的时间及两类通知的情况；如未见完成通知，回到应用记录该轮显示的状态。

## 准备测试会话

1. 服务管理员创建独立测试 Key。文字聊天选 `chat`，图片和 WAV 同时选 `file`。准备第二把可撤销的测试 Key 以及独立测试服务 B。密钥在设备上直接输入。
2. 让手机访问证书受信任的 AstrBot HTTPS 基础地址。若使用反向代理，可仅将 `POST /api/v1/chat`、`GET /api/v1/chat/sessions` 和 `GET/POST /api/v1/file` 转发到 AstrBot，限制在测试网络内。管理面板仍由管理员在电脑上访问。命名 Key 的验证只查询会话列表，获得文件操作权限需用实际上传和下载确认。
3. 跨端另需交付目录里的 `shared-service.zip`。按其中指南在电脑配置 AstrBot、启动个人共享服务和 Caddy，手机填写可达的 HTTPS 共享地址。PC 的回环地址只供 PC 使用。创建码、一次性加入码按需生成。生产密钥、配对码、真实聊天和设备标识均不必附在反馈中。
