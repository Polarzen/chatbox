# Chatbox 0.1.15 Windows 发布验收

本轮核对全局快捷键的首次注册时机，以及后台回复提醒开关对尚在等待附件缓存的回复是否生效。0.1.14 的托盘、全局唤起和通知定位已有安装版记录。[0.1.14 验收记录](WINDOWS_014_RELEASE_ACCEPTANCE.md)

## 0.1.14 正式安装版复现

**首次启动即占用快捷键。** 使用全新配置启动，以及使用缺少 `hotkeyEnabled` 字段的旧配置启动时，「全局快捷键」均显示开启。两次在外部程序尝试注册 Ctrl+Alt+J 均报告该键已被占用。

**保存关闭后仍收到迟到通知。** 独立回环服务让纯图片回复的 SSE 流先结束，再暂停首次附件 GET。聊天历史已写入本机，此时 Windows 通知数为 0。在安装版中关闭提醒并成功保存，切回记事本后放行下载。480 × 260 像素的 PNG 已缓存，Windows 随即显示 1 张原生通知。实际点击该通知后回到原会话第 3 轮。整轮有 1 次聊天提交、0 次上传。
