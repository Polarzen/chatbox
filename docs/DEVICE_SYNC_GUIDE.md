# 0.1.19 · 在电脑和手机之间接着聊

## 安装或从 0.1.18 升级

覆盖升级会保留两端各自在本机创建的聊天记录、草稿和已保存的附件。旧版「电脑档案连接」和「单会话共享」入口已退役。如果有重要消息只在旧客户端的远端缓存中可见，请在升级前另存正文。此类缓存不会自动转成本机会话。

1. Windows 上按原服务的运行情况准备升级，然后退出 Chatbox（包括托盘），备份 `%LOCALAPPDATA%\Chatbox`。从未启动共享服务的用户可直接退出并备份。
   - 如果已在自带运行时的前期 0.1.19 测试包中开启设备服务，请先在原窗口的设备设置点「停止共享」，等服务处理完当前请求并停止，再退出。覆盖安装后，在新版设备设置点「启动服务」即可沿用原有设备绑定。如果原先启用了登录自启，请重新勾选「Windows 登录后自动恢复服务」。
   - 如果电脑上独立部署过旧共享服务，先核对旧会话里待发送的消息，手动正常停止仍在运行的旧服务，再备份整个共享数据目录（含 SQLite 及其同目录辅助文件）和代理配置。保留原数据库路径，首次配对时会用到。
2. 核对同批 Windows MSI 和 Android APK 的 SHA-256。在电脑运行 0.1.19 MSI，沿用原安装目录。Android 8 及以上可在手机文件管理器中点同签名的 0.1.19 APK 覆盖安装。手机系统备份不包含 Chatbox 私有数据，升级前请另存重要正文和原始附件。若提示签名不一致，保留现有安装和数据，取得匹配签名的 APK。[Windows 安装说明](../desktop/README.md) · [Android 覆盖安装说明](ANDROID_PARITY_QA.md)
3. 若要开启设备共享，电脑需要能运行 Python 3.10 或以上版本。可启动已装好的 AstrBot Launcher 实例，使用其 Python 环境，也可安装 Windows 版 Python 并让 `py.exe` 或 `python.exe` 出现在 PATH。MSI 自带共享服务脚本。要生成新回复，还需运行原 Launcher 实例或让电脑能访问原来使用的 AstrBot 部署。

## 首次连接

两端首次引导都可选「仅在本机使用」。稍后从 Windows「连接设置 → 连接我的手机 · 设备共享设置」或手机「最近对话 → 设备设置 → 连接我的电脑」进入。

1. **在电脑找到原 AstrBot。** 选择引导中对应的 Launcher 实例或已有服务档案，也可输入实际的 AstrBot 基础地址并点「使用此地址」。选已有密钥，或输入有 `chat` 权限的 AstrBot OpenAPI Key，点「安全保存并验证」。看到「AstrBot 已验证」后点「下一步」。来源设备直接发送图片或语音时，其 Key 还需 `file` 权限。
2. **选手机连接方式。** 两种方式都将手机流量送到电脑上的**受限网关**，默认目标为 `http://127.0.0.1:18766`。在「部署配置与 ngrok 授权」改过端口时，代理目标须用相同端口。

   | 连接方式 | 在 Windows 上操作 |
   | --- | --- |
   | 跨网络 · ngrok | 从官网下载 Windows 版并安装，登录自己的 ngrok 账号。已有固定域名时，在「已有 ngrok HTTPS 域名」填账号获配的完整 HTTPS 地址。在「部署配置与 ngrok 授权」可指定 `ngrok.exe` 的完整路径。授权框可粘贴该账号的 authtoken，也可粘贴官网提供的完整 `ngrok config add-authtoken TOKEN` 命令。ngrok 已在此用户下授权时可留空 token。域名留空时会尝试复用现有隧道，或使用账号可用地址。已有隧道须只提供 HTTPS、关闭请求检查并指向上面的受限网关。 [ngrok Windows 下载](https://ngrok.com/download/windows) · [ngrok 账号](https://dashboard.ngrok.com/) |
   | 局域网或已有可信 HTTPS 域名 | 在这台电脑上的 HTTPS 反向代理中，把用于设备同步的域名转发至上述受限网关。手机和电脑均须能解析、访问该域名并信任证书。局域网方式让手机连接相应 Wi-Fi。在「手机 HTTPS 地址」填写完整 HTTPS 地址，可带端口，不加路径或查询参数。沿用旧版局域网证书时，在局域网 DNS 中将 `chatbox.home.arpa` 指向电脑。Android 对用户安装的 CA 仅为此域名开放信任。 |

   **请按用途填地址。**「AstrBot 地址」供电脑请求模型。「本机共享服务」是管理和历史服务的回环地址，端口由程序分配，只在电脑使用。手机填「手机 HTTPS 地址」，其代理目标只选受限网关。这样手机入口仅开放设备配对、读写会话等指定操作。邀请签发、设备撤销、上游配置和 AstrBot WebUI 均留在电脑侧。
3. **沿用旧共享数据库的用户在此步选库。** 核对引导显示的路径，可点「使用找到的旧部署数据库」，或在「原共享 SQLite 数据库路径」填原文件的完整路径。必须选择与原库匹配的 AstrBot 部署，并保持原服务已停止。全新部署留空即可。首次配置后数据库路径固定。新版共享服务可在电脑上复用原库，并核对原档案或房间的主人身份。旧凭据的授权仍限于原档案或原房间。原代理若指向 `8765`，请按上一步改为受限网关。两端使用下一步生成的设备配对码确认新的共享范围。
4. **核对数量并配对。** 在电脑查看预计导入的档案数和已有会话数。勾选「允许这两台设备共享上述范围」，按需要选择「Windows 登录后自动恢复共享服务」，点「开启共享并生成配对码」。手机选「连接我的电脑」扫描二维码，也可点「手动输入地址和配对码」，填电脑显示的手机 HTTPS 地址和一次性短码，再点「查看共享范围」。核对电脑标识、两端预计的档案数与会话数，点「确认范围并连接」。配对码十分钟内有效，过期后在电脑重新生成。

## 主题和聊天背景

在 Windows 或安卓聊天页点「主题」，选择主题色与自定义图片，用下方的对话预览检查文字和气泡效果。应用后，已配对设备会同步浅色或深色模式、主题色、背景图片和虚化强度。虚化只作用于聊天背景图。未配对时也可以在本机使用这些设置。

已配对设备需升级到支持主题的版本。若升级后仍提示电脑端共享服务版本较旧，请在电脑设备设置中点「停止共享」，再点「启动服务」。已配对身份会保留。之前启用了登录自动恢复的用户，重启服务后可重新勾选该选项。

## 从「最近对话」开始

- 两端共享现有及以后新增档案中已提交的会话和消息。首次同步时让两端应用保持运行。在「最近对话」按来源辨认同名会话，打开旧问答后可在普通输入框续聊。也可在手机点「＋ 新建会话」，按界面选择可用档案，发送第一条文字后再到另一端查看。电脑和手机使用不同地址连接同一个 AstrBot 时，如只可阅读，在电脑「待关联的手机来源」选已验证的对应档案，核对后点「确认是同一 AstrBot 并关联」。
- 空会话、未发出的文字和附件草稿保存在编辑设备。已发图片和语音的原件也在来源设备，另一端看到文字记录或附件提示；要发送附件，回到会话所属档案的来源设备。缺失正文、未知来源、尚待核对的旧记录，以会话中的状态提示为准。OpenAPI Key、管理员登录态不经过设备历史同步。
- 手机「在本机隐藏」只影响这台手机的列表。电脑删除会话时看确认框的范围，提示「从两台设备的共享目录移除」的会话会同时删除电脑本机记录，并在下次同步后移出共享目录。电脑设备设置中的「撤销」会立即取消所选手机的服务访问权，离线手机下次联系服务后清除绑定及远端缓存，手机原有本地历史保留。手机的「断开设备并清除缓存」可用于本机解绑，吊销访问权仍须在电脑操作。

## 离线、重启或更换地址

| 情况 | 如何继续 |
| --- | --- |
| 收起或退出 Windows 聊天窗口 | 独立的共享服务可继续运行，手机可读取已同步的记录。生成新回复还需要 AstrBot、模型和手机 HTTPS 入口在线。要发布仅存在电脑上的历史、处理电脑端待发内容或查看手机的新消息，再打开 Windows Chatbox。 |
| 电脑睡眠、关机或重启 | 睡眠和关机期间手机无法联系共享服务。唤醒或重启后确认 AstrBot 和代理在线。启用登录自启会在该 Windows 用户登录后恢复共享服务；未启用时到电脑设备设置点「启动服务」，再点「检查入口」。点「停止共享」会同时关闭登录自启，保留设备绑定。 |
| 手机断网 | 仍可阅读已缓存的历史。可续聊会话中已点发送的普通文字在本机排队。联网后回到应用，或到「设备设置 → 检查连接」补齐。若提示发送结果未知，先核对原轮，再依提示处理，避免另发一份相同消息。 |
| 隧道域名变更 | 在电脑设备设置点「更改 AstrBot 或手机入口」配置新入口并检查，记下界面显示的新 HTTPS 地址。在手机「设备设置 → 更新连接地址」填入该地址，点「验证并更新」。手机核对原服务身份后沿用配对。电脑检查通过后，仍须用手机所在的网络实际连通。 |
