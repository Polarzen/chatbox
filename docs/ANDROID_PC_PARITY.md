# Windows 与 Android 功能对照 · 0.1.17 初验

日常 Windows 功能以已发布的 0.1.15 为基线。两端 0.1.17 候选版保留本机会话，并可把选定会话接入个人共享服务。当前 Android 修复候选为 `640786d7`（SHA-256 前八位），从 0.1.16 直接覆盖后保留两轮历史及草稿，API 26 模拟器六项验收通过，后台延迟回复可由通用通知回到原轮。Redmi Turbo 3 已覆盖安装，瑶实测后台慢回复完成后点提醒可冷启动回原轮。下表标明当前候选的通知、搜索及心率结果，其余真机结果对应上一候选 `83603683`，五组对照图也来自上一轮。瑶已确认 `640786d7` 初验通过；Polarzen 同机独立复验通过，操作回执见搜索一行。[本轮验收记录](ANDROID_PARITY_ACCEPTANCE.md) · [Windows 基线](../desktop/README.md) · [安装与现场验收](ANDROID_PARITY_QA.md)
