# Windows 与 Android 功能对照 · 0.1.17 初验

日常 Windows 功能以已发布的 0.1.15 为基线。两端 0.1.17 候选版保留本机会话，并可把选定会话接入个人共享服务。Redmi Turbo 3 已核验安装交付 APK（SHA-256 前八位 `83603683`）。表内列明 Redmi 离线实测，其余 Android 界面实测来自 API 26 模拟器。Redmi 联网、真实手环及瑶本人初验仍待回执。[本轮验收记录](ANDROID_PARITY_ACCEPTANCE.md) · [Windows 基线](../desktop/README.md) · [安装与现场验收](ANDROID_PARITY_QA.md)

| 用户操作 | Windows 入口 | Android 入口 | 本轮证据与平台差异 |
| --- | --- | --- | --- |
| 连接服务、切换命名密钥 | 顶栏连接状态和密钥菜单，可选 Launcher 或手动地址 | 「更多操作 → 连接设置」，添加 HTTPS 服务、命名密钥并验证 | 模拟器实测失效 Key 切换出现拒绝提示，原活动 Key 可发文。切到 B 后搜不到 A 的记录，重启仍在 B。手机密钥由 Keystore 保护。 |
| 管理本机会话与草稿 | 最近对话侧栏新建、点选，行末菜单重命名或删除 | 顶栏打开「最近对话」，同样可新建、改名、恢复默认名、确认删除 | Redmi 新会话里编辑草稿时软键盘和发送键均可见，强停再冷启动后逐字恢复。模拟器横屏可并列，0.1.16 覆盖升级保留旧问答、实际发送的一轮和草稿，重启未重复导入。 |
| 发送、阅读与搜索 | 输入区发送；气泡复制、重试；「回到最新」；放大镜或 Ctrl+K | 固定输入区与发送键；气泡「复制正文」「重试」；放大镜搜索当前档案的标题、提问和回复 | 手机收齐 70 行回复，上滑后可返回末行。点助手命中片段可跨会话跳回原轮、高亮并恢复该会话草稿。 |
| 本地图片、语音 | ＋ 多选、拖入文件或 Ctrl+V 粘贴截图；录音、停止、试听；回复内看图、播 WAV | ＋ 选图或粘贴图片，也可从系统分享；输入区录音，草稿中预览、移除，回复内看图、播 WAV | 手机系统选入两图，录音切后台收尾，文字、两图、WAV 重启后保留；发送后打开回复图像并点播 WAV。模拟器没有声学回放验收。 |
| 跨端接续 | 当前会话顶栏「共享」，创建房间或加入 | 「更多操作 → 跨设备共享会话」，使用一次性码加入 | Windows 发出「本轮代号是青松47」，手机看到问答并追问，得到「青松47」。共享输入框发送文字，旧附件以提示随历史导入；图片、录音文件及未发草稿保存在原设备。[配对与同步范围](SHARED_CHAT_GUIDE.md) |
| 外观、系统入口与通知 | 顶栏外观、置顶；桌面设置管理托盘、全局热键及后台回复提醒 | 「更多操作 → 窗口外观」切换明暗、开启后台回复通知；系统通知权限及通知渠道共同控制展示 | Redmi 已切换深色、查看深色聊天页并恢复默认外观。模拟器另验横竖屏、130% 字号和软键盘。桌面窗口透明度、置顶、全局热键和托盘属于 Windows。Android 本地回复完成提醒可定位档案、会话、原轮；共享房间打开或回到前台时刷新。 |
| WhaleTask | 已验证的本机 Launcher 会话中发送纯文字 `/task help` 或 `/task list`，登录 Dashboard 后再次发送 | 本地或共享输入框识别 `/task`，提示改到 Windows Launcher 执行 | 代码已核对命令限制。手机不保存 Dashboard 登录信息。 |
| 手环心率 | Windows 有独立实验实现；已发布 0.1.15 没有日常心率入口 | 「更多操作 → 心率 → 扫描设备」，选择标准 BLE 心率手环 | 模拟器实测拒权及无 BLE 硬件提示。实现会将最近 10 秒内的 BPM 与接收时间附在普通消息，斜杠命令跳过，停止、断线或过期后发送原文。真实手环的广播、订阅和带心率发送待现场验收。 |
