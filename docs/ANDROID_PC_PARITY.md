# Windows 与 Android 功能对照 · 0.1.17 初验

日常 Windows 功能以已发布的 0.1.15 为基线。两端 0.1.17 候选版保留本机会话，并可把选定会话接入个人共享服务。本表的 Redmi Turbo 3 真机结果对应候选 APK `83603683`（SHA-256 前八位），另列 API 26 模拟器的实测结果。[本轮验收记录](ANDROID_PARITY_ACCEPTANCE.md) · [Windows 基线](../desktop/README.md) · [安装与现场验收](ANDROID_PARITY_QA.md)

| 用户操作 | Windows 入口 | Android 入口 | 本轮证据与平台差异 |
| --- | --- | --- | --- |
| 连接服务、切换命名密钥 | 顶栏连接状态和密钥菜单，可选 Launcher 或手动地址 | 「更多操作 → 连接设置」，添加 HTTPS 服务、命名密钥并验证 | Redmi 验证 HTTPS 配置，前台两轮均收到文字回复，期间没有活动通知。模拟器实测失效 Key 切换出现拒绝提示，原活动 Key 可发文。切到 B 后搜不到 A 的记录，重启仍在 B。手机密钥由 Keystore 保护。 |
| 管理本机会话与草稿 | 最近对话侧栏新建、点选，行末菜单重命名或删除 | 顶栏打开「最近对话」，同样可新建、改名、恢复默认名、确认删除 | Redmi 新会话里编辑草稿时软键盘和发送键均可见，强停再冷启动后逐字恢复。模拟器横屏可并列，0.1.16 覆盖升级保留旧问答、实际发送的一轮和草稿，重启未重复导入。 |
| 发送、阅读与搜索 | 输入区发送；气泡复制、重试；「回到最新」；放大镜或 Ctrl+K | 固定输入区与发送键；气泡「复制正文」「重试」；放大镜搜索当前档案的标题、提问和回复 | Redmi 搜索后跳回原轮，重启恢复同一在线会话。模拟器收齐 70 行回复，上滑后可返回末行。点助手命中片段可跨会话跳回原轮、高亮并恢复该会话草稿。 |
| 本地图片、语音 | ＋ 多选、拖入文件或 Ctrl+V 粘贴截图；录音、停止、试听；回复内看图、播 WAV | ＋ 选图或粘贴图片，也可从系统分享；输入区录音，草稿中预览、移除，回复内看图、播 WAV | Redmi 从系统分享和选择器导入合成 PNG；实际图文上传后可打开已发原图，该轮只收到文字回复。机主录音时按 Home，返回后听到短句，草稿中 0:03 的 WAV 已移除，未上传。模拟器另验两图与 WAV 的混合草稿恢复、发送及回复媒体打开。 |
| 跨端接续 | 当前会话顶栏「共享」，创建房间或加入 | 「更多操作 → 跨设备共享会话」，使用一次性码加入 | Windows 发出「本轮代号是青松47」，Android 模拟器看到问答并追问，得到「青松47」。共享输入框发送文字，旧附件以提示随历史导入；图片、录音文件及未发草稿保存在原设备。[配对与同步范围](SHARED_CHAT_GUIDE.md) |
| 外观、系统入口与通知 | 顶栏外观、置顶；桌面设置管理托盘、全局热键及后台回复提醒 | 「更多操作 → 窗口外观」切换明暗、开启后台回复通知；系统通知权限及通知渠道共同控制展示 | Redmi 已验深色与恢复默认、通知拒权及设置内恢复授权。两次较慢的后台回复均超时且无通知。一次快速回复出现通用通知，点击后可冷启动回原轮。模拟器实测通知可定位原轮，另验横竖屏、130% 字号和软键盘。置顶、窗口透明度、热键和托盘为 Windows 功能。共享房间回前台时刷新。 |
| WhaleTask | 已验证的本机 Launcher 会话中发送纯文字 `/task help` 或 `/task list`，登录 Dashboard 后再次发送 | 本地或共享输入框识别 `/task`，提示改到 Windows Launcher 执行 | 代码已核对命令限制。手机不保存 Dashboard 登录信息。 |
| 手环心率 | Windows 有独立实验实现；已发布 0.1.15 没有日常心率入口 | 「更多操作 → 心率 → 扫描设备」，选择标准 BLE 心率手环 | Redmi 机主选中小米手环 9，实时 BPM 可见，点「停止」后清除。另一次机主在手环端关闭广播，看到「设备已断开」。随后手机无数字读数，恢复「扫描设备」。模拟器实测拒权及无 BLE 硬件提示。断线后的独立测试轮次在服务端只含原文。实现仅对普通消息附加 10 秒内的读数及接收时间；机主此前测试文本的附加结果仍待核实。 |
