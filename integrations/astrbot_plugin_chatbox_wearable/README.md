# Chatbox 手环数据

这个 AstrBot 服务端插件在已配对的 Chatbox 个人会话中提供 `query_wearable_data`，并在没有新消息时处理运动和晨间任务。已使用 AstrBot 4.29.4 验证插件加载、工具执行和定时回调。

## 安装和授权

1. 在手机 Chatbox 的“手环数据”设置中选择来源、指标以及自己的个人档案，完成系统授权。用手机生成这个档案的插件凭据。
2. 在目标 AstrBot 实例的插件管理中安装交付的插件 ZIP。也可以把本目录复制为该实例的 `data/plugins/astrbot_plugin_chatbox_wearable/`，再重新加载插件。
3. 在插件配置的 `service_url` 填写该手机配对使用的 Chatbox 共享服务 HTTPS 站点。如果 AstrBot 与共享服务运行在同一台电脑，可填写已核对端口的 HTTP 回环地址，例如 `http://127.0.0.1:18766`。在 `plugin_token` 填写手机刚生成的专用凭据，保存并重载。该令牌随 AstrBot 私有配置保存。
4. 在对应档案中启用插件并选用支持工具调用的模型。在原有 Chatbox 手机或 Windows 聊天输入框说“今天训练完有点累”，在 AstrBot 工具记录中核对模型是否调用了 `query_wearable_data`。发送者、会话和本轮请求编号由 WebChat 事件与共享服务共同核实。

在手机设置中分别选择运动处理、晨间时间、等待窗口和是否发送摘要。启用提醒时选择归属已核实的个人会话。关闭提醒仍可执行查询。AstrBot 和共享服务均需运行。插件每分钟通过 AstrBot 的基础定时任务检查一次，晨间时间以手机设置的时区为准。共享服务保存任务进度、等待截止时间和投递结果。两端从共享会话同步同一条助手消息。

## 数据和撤销

聊天查询默认只请求一项指标的摘要。例如 `{"metric":"exercise"}` 查询最近运动。可选的 `period` 参数对步数、睡眠、运动及运动心率分别默认为 `today`、`last_night`、`latest`、`latest`。查询明确时段时，在同一个参数传入带 UTC 偏移的起止时间，例如 `2026-11-24T18:00:00+08:00/2026-11-25T07:00:00+08:00`，最长 30 天。格式错误会返回修正提示。用户明确要求分段或序列时才使用 `granularity="detail"`。返回值带来源、单位、时间和状态，手机离线或数据过期时应参照最后同步时间解读。

聊天查询的结果会进入当前模型上下文。AstrBot 4.29.4 的工具运行日志也可能记录返回值，模型提供方按该档案现有配置处理数据。后台任务通过共享服务查询和完成，摘要仅投递到配置指定的会话。

在手机上停止共享、撤销对应指标或清除已同步健康缓存。需要换凭据时在手机重新生成，再更新插件配置并重载。服务收到撤销后执行权限变更。若要移除已经生成的回复或运行记录，需分别按 Chatbox、AstrBot 及所用模型提供方的历史记录管理方式处理。

## 隔离验证

从仓库根目录运行以下命令，把两个占位路径改为供测试的 AstrBot 安装位置。脚本使用临时数据目录、真实插件管理器、WebChat 适配器、工具循环和调度器。模型响应与回环健康服务使用固定样本。

```powershell
$env:PYTHONPATH = '<AstrBot core 目录>'
& '<AstrBot 虚拟环境的 python.exe>' -B integrations/tests/test_chatbox_wearable.py -v
```
